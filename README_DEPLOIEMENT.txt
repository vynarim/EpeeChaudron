L’ÉPÉE ET LE CHAUDRON — MAQUETTE V3

Contenu du dossier
- index.html : page principale
- assets/css/style.css : styles
- assets/js/main.js : menu, galerie, lightbox, onglets
- assets/js/photos.js : liste des photos affichées dans la galerie
- assets/img/full : images optimisées grand format
- assets/img/thumbs : miniatures optimisées

Déploiement
1. Dézipper le dossier.
2. Envoyer tout le contenu du dossier epee-chaudron-v3 sur le serveur web.
3. Remplacer l’ancien index par ce index.html.

Points à vérifier avant mise en ligne
- Remplacer l’adresse contact@epee-chaudron.fr si elle n’est pas correcte.
- Ajouter éventuellement le numéro de téléphone si l’association souhaite l’afficher publiquement.
- Tester sur un téléphone réel, puis sur ordinateur.

Ajouter une photo
1. Copier la photo optimisée dans assets/img/full et une miniature dans assets/img/thumbs.
2. Ajouter une ligne dans assets/js/photos.js avec src, thumb, title, category et alt.
